## 核心功能模块

### 1. 认证模块
- **AuthController**: 处理用户登录认证
- **UserService**: 提供用户登录验证功能
- **LoginRequest/LoginResponse**: 登录请求和响应数据结构

### 2. 学生管理模块
- **StudentController**: 学生基本信息管理
- **AdminStudentController**: 管理员学生管理（增删改查）
- **UserStudentController**: 学生用户相关操作
- **StudentService**: 学生信息服务
- **StudentRepository**: 学生数据访问

### 3. 分数管理模块
- **ScoreController**: 处理学生分数（德育、智育、体育）的查询和导入
- **MoralEducationService**: 德育分数服务
- **IntellectualEducationService**: 智育分数服务
- **PhysicalEducationService**: 体育分数服务
- **ImportService**: 分数数据导入服务

### 4. 基础信息管理
- **AdminClassController**: 班级管理
- **AdminCollegeController**: 学院管理
- **AdminMajorController**: 专业管理
- **ClassInfoService/CollegeService/MajorService**: 对应服务

### 5. 角色权限模块
- **RoleController**: 角色管理
- **RoleService**: 角色服务
- **UserRoleService**: 用户角色关联服务
- **RoleType**: 角色类型枚举

## 数据模型

### 学生相关
- **Student**: 学生基本信息
- **ClassInfo**: 班级信息
- **College**: 学院信息
- **Major**: 专业信息

### 分数相关
- **MoralEducation**: 德育分数
- **IntellectualEducation**: 智育分数
- **PhysicalEducation**: 体育分数

### 用户相关
- **User**: 用户信息
- **Role**: 角色信息
- **UserRole**: 用户角色关联

## API 接口

### 认证接口
- `POST /api/auth/login` - 用户登录

### 学生管理接口
- `GET /api/students` - 查询学生列表
- `GET /api/students/{id}` - 根据ID查询学生
- `POST /api/students` - 新增学生
- `PUT /api/students/{id}` - 更新学生信息
- `DELETE /api/students/{id}` - 删除学生

### 管理员学生管理接口
- `GET /api/admin/students` - 分页查询学生列表（支持关键词搜索）
- `GET /api/admin/students/{id}` - 根据ID查询学生
- `GET /api/admin/students/no/{studentNo}` - 根据学号查询学生
- `POST /api/admin/students` - 新增学生
- `PUT /api/admin/students/{id}` - 更新学生信息
- `DELETE /api/admin/students/{id}` - 删除学生
- `DELETE /api/admin/students/batch` - 批量删除学生

### 分数管理接口
- `GET /api/scores/moral/{studentId}` - 查询德育分
- `GET /api/scores/intellectual/{studentId}` - 查询智育分
- `GET /api/scores/physical/{studentId}` - 查询体育分
- `GET /api/scores/student/{studentId}` - 查询学生所有分数
- `GET /api/scores/all` - 批量查询所有学生分数
- `POST /api/scores/import` - 导入分数数据（支持Excel和CSV）

### 基础信息管理接口
- **学院管理**: `GET/POST/PUT/DELETE /api/admin/colleges`
- **专业管理**: `GET/POST/PUT/DELETE /api/admin/majors`
- **班级管理**: `GET/POST/PUT/DELETE /api/admin/classes`

## 技术特点

1. **分层架构**: 清晰的控制器层、服务层、数据访问层分离
2. **RESTful API**: 符合REST规范的接口设计
3. **Spring Boot**: 基于Spring Boot 3.2.0框架
4. **JPA**: 使用Spring Data JPA进行数据访问
5. **多类型分数管理**: 支持德育、智育、体育三种分数类型
6. **数据导入**: 支持Excel和CSV格式的分数数据导入
7. **分页查询**: 支持学生列表的分页查询和关键词搜索
8. **CORS支持**: 跨域请求支持

## 运行要求

- Java 17+
- Maven 3.6+
- MySQL 8.0+

## 启动方式

1. 配置数据库连接（application.yml）
2. 执行 `mvn clean install` 构建项目
3. 运行 `BackendApplication` 主类

## 总结

本项目是一个学生成绩管理系统的后端部分，主要功能包括：
- 用户认证登录
- 学生信息管理
- 学院、专业、班级管理
- 德育、智育、体育分数管理
- 分数数据导入
- 角色权限管理

系统采用分层架构，代码结构清晰，功能完善，为前端提供了丰富的API接口。
